# Universal Agent Governance & Execution Rules

## 1. Mandatory Pre-Execution Protocol
- **Step 1:** Read `ROADMAP.md` to identify your assigned task ID and dependencies.
- **Step 2:** Read `BLACKBOARD.md` to ensure no conflicting file edits or active locks exist.
- **Step 3:** Read `.agent-rules.md` (this file) for non-negotiable tech stack constraints.

## 2. Mandatory Post-Execution Protocol
- **Step 1:** Append an entry to the `Event Stream` in `BLACKBOARD.md` detailing every file created, modified, or deleted.
- **Step 2:** Update task status checkboxes in `ROADMAP.md` (`[ ]` -> `[x]`).
- **Step 3:** Update the current milestone and completion percentage in `PROGRESS.md`.

## 3. Strict Architectural Invariants
- **No Direct Transitive Edits:** Never modify a file outside your assigned task scope without logging it in `BLACKBOARD.md`.
- **Zero Hallucinated Imports:** Only use packages explicitly listed in dependency manifests (`package.json`, `pyproject.toml`, etc.).
- **Atomic Operations:** If a step fails or tests break, rollback file edits and log the failure stack trace in `BLACKBOARD.md`.
